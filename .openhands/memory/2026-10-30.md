## Expensive lessons
- The web app is **inlined** `@phirst/core`; after a core change rebuild core *and* web and
  restart `next start`, or you get stale-bundle bugs.
- Build web with `NODE_ENV=production npm run build -w @phirst/web` — the sandbox's global
  `NODE_ENV=development` breaks `next build`.
- `apps/web` has **no** `.env.local` here; env lives in the repo-root `.env` (root `.gitignore`
  ignores `.env`). `next.config.mjs` proxies `/api/*` to `PHIRST_API_INTERNAL ?? :12001`.
- Start services: `npm run start:api` (root, tsx) and `npm run start -w @phirst/web` from
  `apps/web`. Logs to `.run/` (gitignored).
- Postgres runs in container **`phirst-pg`** (user `phirst`, db `phirst`). Fresh DB →
  `ownerExists:false`, so run `/api/auth/setup` first.
- `case` globs in bash do **not** support `\|` alternation — a smoke assertion using it
  silently never matches. Use a plain substring.
